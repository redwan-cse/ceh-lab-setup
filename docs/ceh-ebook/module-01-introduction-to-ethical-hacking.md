# Module 01: Introduction to Ethical Hacking - Lab Guide

## Tools Used & Purpose

* Module 01 is an introductory theoretical overview in the official EC-Council CEH v13 curriculum covering ethical hacking concepts, legal frameworks, and security methodologies; no hands-on lab tools are assigned to this module.

---

## Lab Notice
Module 01 is an introductory theoretical overview in the official EC-Council CEH v13 curriculum. It establishes essential security definitions, frameworks (Cyber Kill Chain, MITRE ATT&CK), risk management calculations, and cyber laws. No hands-on lab exercises are assigned to this foundational module. Practical hands-on lab exercises commence in Module 02 (Footprinting and Reconnaissance).
